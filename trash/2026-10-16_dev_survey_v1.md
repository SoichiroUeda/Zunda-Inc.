# 開発希望者アンケート（案）

- **版:** v1（2026-10-16）
- **目的:** 開発責任者と分担を決めるため、開発を希望してくれた人の経験と環境を把握する。
- Google フォームなどにそのまま転記できる形にしています。

---

## A. 基本

1. お名前（ニックネーム可）
2. 学部・学年

## B. 経験

3. プログラミング経験はどのくらいありますか？（1つ選択）
   - まったくない
   - 授業・独学で少し触った程度
   - 自分で小さなプログラム・Web ページなどを作ったことがある
   - アプリ・Web サービスを作って公開したことがある
4. 使ったことのある言語をすべて選んでください（複数選択）
   - Python / JavaScript・TypeScript / Dart（Flutter） / Swift / Kotlin・Java / C・C++ / その他（　）
5. 次のうち使ったことがあるものをすべて選んでください（複数選択）
   - Git / GitHub
   - Flutter
   - Firebase
   - スマホアプリの開発（iOS / Android）
   - AI の API（Gemini・OpenAI・Claude など）をプログラムから呼んだ
   - AI コーディングツール（Claude Code・Cursor・GitHub Copilot など）
6. 自分で開発環境を整えたこと（SDK のインストール、エラーを調べて解決するなど）はありますか？（はい / いいえ / わからない）

## C. 環境

7. 開発に使えるパソコンの OS（Mac / Windows / Linux / 持っていない）
8. 普段使っているスマホ（iPhone / Android）
9. Claude Code などの有料 AI ツールを契約していますか？（している / していない / 検討中）

## D. 参加

10. アルファ版の1週間に使える時間（合計）
    - 3時間未満 / 3〜6時間 / 6〜10時間 / 10時間以上
11. 11〜12月に使える時間（週あたり）
    - 1時間未満 / 1〜3時間 / 3〜5時間 / 5時間以上
12. 開発責任者（取りまとめ役）をやってみたいですか？（やりたい / 条件次第 / 担当者として参加したい）
13. 特にやってみたいこと（画面づくり / AI 連携 / 通知 / データ保存 / なんでも）
14. 不安なこと・質問があれば自由にどうぞ

---

## 回答の見方（オーナー用）

- **開発責任者の候補：** Q3 が「作ったことがある」以上、かつ Q5 で Git/GitHub、Q6 が「はい」の人。
- **iOS 担当の候補（ベータ以降）：** Q7 が Mac の人。
- 経験者が1人もいない場合は、アルファ開始前にぷらぐら（または外部の経験者）がリポジトリと環境構築手順を用意してから始める。
